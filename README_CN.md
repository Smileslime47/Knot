# Knot - 一个基于Kotlin实现的Rope数据结构库

## 为什么要用Rope

Rope是一种线性数据结构，旨在将所有操作（插入、查询、删除）的复杂度都优化为O(logN)，在大部分情况下你可能并不需要Rope，String和List完全可以完成你的需求

Rope最经典的场景在于大规模文档的编辑上，对于String（本质上是一个Char数组） ，当你在一个具有M行的文档中的第N行按下回车时，本质上做了这样的一件事：将第[N+1,M]行内容移动到第[N+2,M+1]行，然后将第N行设置为空行，显而易见的，这是一个O(N)的操作，当文档达到1MB以上时，可能就会有一定的性能损耗，这一点在List上是相同的

Rope的另一个场景在于索引反查上，当你需要快速查询到一个元素在线性数据结构上的索引时，往往需要O(N)的时间复杂度，即便我们将索引信息缓存在元素字段里，也仍然需要在插入/删除第N个元素时，更新第N+1个以后的元素的字段。
